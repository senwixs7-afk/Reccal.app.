RECALL — Android-проект
=======================

В проект уже включён сайт Recall и настроена облачная сборка APK через GitHub Actions.
Это ИСХОДНЫЙ ПРОЕКТ, не готовый APK.

СБОРКА С ТЕЛЕФОНА (без Android Studio)
--------------------------------------
1. Откройте github.com в браузере и войдите в свой аккаунт GitHub (или создайте его).
2. Создайте новый репозиторий. Для простоты можно выбрать Public; тогда сборка GitHub Actions
   на стандартном сервере бесплатна. Не загружайте в репозиторий личные данные.
3. Откройте новый репозиторий и выберите Add file -> Upload files.
4. Распакуйте ZIP проекта на телефоне через ZArchiver. Загрузите ВСЕ файлы и папки
   из папки RecallAndroid в корень репозитория. Включая скрытую папку .github.
5. Нажмите Commit changes.
6. Откройте вкладку Actions. Выберите workflow "Build Recall APK" и нажмите Run workflow,
   если он ещё не запустился автоматически после загрузки файлов.
7. Дождитесь завершения сборки со статусом Success.
8. Откройте завершённый запуск workflow. Внизу страницы найдите Artifacts и скачайте
   Recall-debug-APK. Распакуйте загруженный ZIP — внутри будет app-debug.apk.
9. Откройте APK на телефоне и следуйте системным инструкциям Android для установки.

Если сборка завершится ошибкой, откройте её журнал (Build debug APK) и пришлите скриншот.
Не отправляйте никому пароль, коды входа или резервные коды GitHub.

ДАННЫЕ RECALL
-------------
Темы хранятся локально внутри приложения. Не удаляйте приложение и не очищайте его данные,
если хотите сохранить базу. Регулярно экспортируйте JSON-копию и храните её отдельно.
Локальное хранение не защищает от удаления приложения, очистки данных, сброса телефона
или поломки устройства.

Технически: applicationId com.recall.study; minSdk 23; targetSdk 35.
